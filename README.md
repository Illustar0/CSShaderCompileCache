## CSShaderCompileCache

An SKSE plugin that caches the shader bytecode Community Shaders compiles, so repeated compiles within a launch and on later launches reuse it instead of compiling again, shortening startup.

Only targets `CS-Jiaye0816-XeSS-AMD-HighMFG-Test1`, with `CommunityShaders.dll` SHA-256 `c6e5c51ecdc808b9b2cecf093be276d30d415769333f2ba80adbb9878c46e178`
